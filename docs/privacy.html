2. Webhosting / Server-Logs

3. Nutzung der API

Bei API-Aufrufen werden Requests verarbeitet, um den Dienst bereitzustellen (Extraktion), Missbrauch zu verhindern (API-Key, Limits) und die Stabilität zu überwachen (Logs).

  • API-Key: wird zur Authentifizierung und zur Zuordnung von Limits/Usage genutzt.
  • Usage: Anzahl der Requests wird gespeichert (z. B. pro Tag), um Limits durchzusetzen.
  • Logs: Request-ID, Pfad, Status, Response-Time (und ggf. weitere technische Daten).

4. Verarbeitung von Inhalten

5. Speicherdauer

Usage-Daten und Logs werden nur so lange gespeichert, wie es für Betrieb/Sicherheit/Abrechnung erforderlich ist. (Du kannst hier später konkrete Zeiträume ergänzen, z. B. Logs 14 Tage.)

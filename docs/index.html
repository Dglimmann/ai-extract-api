Example (API)

Request

curl -X POST https://ai-extract-api.onrender.com/extract \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Invoice No. 2026-001 from ACME GmbH dated 2026-02-01. Total: 249.90 EUR. Due: 2026-02-15.",
    "schema": {
      "supplier_name": null,
      "invoice_number": null,
      "invoice_date": null,
      "due_date": null,
      "total_amount": null,
      "currency": null,
      "vat_amount": null
    },
    "language": "en"
  }'

Response

{
  "data": {
    "supplier_name": "ACME GmbH",
    "invoice_number": "2026-001",
    "invoice_date": "2026-02-01",
    "due_date": "2026-02-15",
    "currency": "EUR",
    "total_amount": 249.9,
    "vat_amount": 39.9
  },
  "warnings": [],
  "confidence": 0.93,
  "model": "gpt-4.1-mini"
}
